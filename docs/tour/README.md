# Product tour

The tour the root [README.md](../../README.md) shows under *Product tour*.

| File | What it is |
| --- | --- |
| `DataMind-product-tour.pdf` | The tour as eleven 16:9 slides. The README links it. |
| `poster.jpg` | The PDF's first slide, which the README shows as a thumbnail. |

**The video is not in the repository.** GitHub plays a video in a README only
when it was uploaded through github.com, which stores it as a
`https://github.com/user-attachments/assets/…` link. A committed `.mp4`
renders as a plain link and stays in the history at full size. To add or
replace it: edit the root README on github.com, drag the `.mp4` onto the line
under the comment in *Product tour*, and commit.

Every screen in both was recorded from the demo build (`frontend/demo/`) over
its sample data, so the tour shows what the demo shows. If a screen changes
enough that the tour no longer matches the product, re-record it rather than
editing the slides.
