# Screenshots

Three images, referenced from the root [README.md](../../README.md) under
*What works today*. Exact filenames — the README links them directly:

| File | What it should show |
| --- | --- |
| `chat.png` | A finished chat answer: the question, the written answer, the *Generated SQL* panel open, the result table and the chart. The header chips (database, model, disclosure policy) should be visible — they are the point of that section. |
| `dashboard.png` | A board with a mix of tile kinds — at least one chart, one table and one big number — so the grid reads as a grid rather than one large chart. |
| `report.png` | The document viewer, scrolled to show a heading, a paragraph of prose, and a numbered figure or table beneath it. |

Capture at a **width of about 1600–1800 px** (the README renders them at 900).
Either theme works, but use the *same* theme for all three. Run against the
bundled demo databases (`sales` or `sakila`) rather than anything real — see the
Quick start.
